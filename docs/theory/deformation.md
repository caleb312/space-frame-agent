# 用于绘图的杆内变形恢复

## 来源与适用范围

教材/课件的 Euler–Bernoulli 单刚、已确认的节点转角正号及截面静力用于本模块。
对节点之间恢复完整曲线属于后处理扩展，明确标为标准理论补充与现有理论推导，
不声称教材提供了本项目三维绘图程序。
基于 docs/theory/member-loads.md 的真实杆端力与局部教材截面内力，
结合该文引用的梁运动学/曲率关系，仍限直杆、等截面、小位移线弹性、无剪切修正与 Saint-Venant 扭转。

## 本项目符号下的关系

局部平动 u/v/w 分别沿 x/y/z；局部转角为课件负右手分量 rx/ry/rz。
教材截面量为 N、Qy、Qz、T、My、Mz，与节点/杆端广义力符号分开。

```text
u'  = N/(EA)
rx' = −T/(GJ)
v'  = −rz
w'  =  ry
v'' = Mz/(EIz)
w'' = My/(EIy)
```

从 i 端已知节点位移/转角积分：

```text
u(x)  = ui + ∫[0,x] N(s)/(EA) ds
rx(x) = rxi − ∫[0,x] T(s)/(GJ) ds
v(x)  = vi − rzi x + ∫[0,x] (x−s)Mz(s)/(EIz) ds
w(x)  = wi + ryi x + ∫[0,x] (x−s)My(s)/(EIy) ds
ry(x) = ryi + ∫[0,x] My(s)/(EIy) ds
rz(x) = rzi − ∫[0,x] Mz(s)/(EIz) ds
```

在跨内集中荷载和均布区间边界分段；当前荷载类型下加权多项式最高三次，三点 Gauss 足够。
全局中心线原始坐标为 Xi+ex·x，全局平动为 Q·[u,v,w]，显示坐标为原始坐标+放大系数×全局平动。
全局转角同样由 Q 转换；展示阶段再按教材附录将转角反号，内力采用已定义教材截面正号。

## 正确性检查

曲线在两端必须与 Solver 节点平动/转角一致，不一致则拒绝绘图。
程序拒绝模型/结果哈希错配；采样显式加入截面请求、荷载位置和区间边界，
集中荷载位置保留 left/right 两组内力，位移/转角连续。

独立参考包含：两端固定均布梁 v=q x²(L−x)²/(24EI)，
悬臂全跨均布梁 v=q x²(6L²−4Lx+x²)/(24EI)，跨内集中力/力矩梁、轴向与扭转解。
变形图不是单纯的节点连线或遗漏荷载特解的三次插值；固定端节点均为零也可产生杆内弯曲。
中心线采样不等于精确连续极值搜索，也不显示实体截面翘曲/应力。
