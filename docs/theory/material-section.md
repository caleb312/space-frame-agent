# 材料与实心圆截面参数工具

## 参考规则说明与符号

项目计算规则，例 IV-1，印刷 p186 / PDF p195，
题面与解答明确给出圆杆半径、弹性模量、泊松比及以下计算公式。
印刷 p186～187 / PDF p195～196 给出程序录入参数。已对照扫描原页，不将公式标为资料缺失。

参考资料写 Jy、Jz 表示形心主惯性矩，Jp 表示圆截面的极面积惯性矩；
本项目接口沿用已有 Iy、Iz、J，实心圆截面下对应 Jy、Jz、Jp。
J 在通用 Solver 中仍代表 Saint-Venant 扭转常数，不对一般截面自动采用 Iy+Iz。

## 公式（参考资料已核对）

参考资料使用直径 D 的惯性矩公式，工具的输入为半径 R，以 D=2R 改写：

```text
G  = E / [2(1+ν)]
A  = π R²
Iy = Iz = π D⁴ / 64 = π R⁴ / 4
J  = Iy + Iz = π R⁴ / 2   （仅本工具的实心圆截面）
```

使用各向同性线弹性材料、实心圆截面及形心轴。不支持空心圆管、矩形或其他截面的自动参数计算；
这些截面仍可按已有 StructuralModel 接口直接提供经确认的 A/Iy/Iz/J。
不把半径解释成直径，不猜 ν，不因单位缺失采用默认值。

标准理论补充仅用于参数适用范围校验：稳定、可压缩的各向同性弹性体要求 E>0、−1<ν<0.5；
本工具拒绝端点 ν=0.5，不声称处理不可压缩材料。可核查
[A. F. Bower《Applied Mechanics of Solids》§3.2](https://solidmechanics.org/Text/Chapter3_2/Chapter3_2.php)。
圆截面 J 的独立核查见 [Cornell 虚拟实验参考资料](https://courses.cit.cornell.edu/virtual_lab/chalktalks/theory/6.shtml)。

## 单位与输出

- E 输入支持 Pa、kPa、MPa、GPa、N/m^2、kN/m^2。
- R 输入支持 m、cm、mm。先统一到 m，再计算二次/四次幂。
- 输出 kN_m：E/G 为 kN/m²；输出 N_m：E/G 为 N/m²。
- A 为 m²，Iy/Iz/J 为 m⁴，ν 无量纲。
- 保留参考资料参数名称与现有接口名称的映射；本工具不涉及转角、荷载和力矩的正负号。
- 显示采用十位有效数字，JSON 保留 Python float 原始结果，显示舍入不回写求解参数。

例如参考资料 E=210GPa、ν=0.3、R=0.05m，以 kN_m 输出：

| 参数 | Python 全精度结果（近似列示） | 单位 |
| --- | --- | --- |
| E | 210000000 | kN/m² |
| G | 80769230.76923077 | kN/m² |
| A | 0.007853981633974483 | m² |
| Iy | 4.908738521234052e−6 | m⁴ |
| Iz | 4.908738521234052e−6 | m⁴ |
| J | 9.817477042468104e−6 | m⁴ |

参考资料程序录入 G=80769000、A=0.007854、Jy=Jz=0.0000049087。
表值已舍入，自动工具使用原始 R/E/ν 全精度计算，不模拟或隐藏这些舍入。
若要严格复现原参考资料程序参数，应显式使用其原始输入文件；不能将全精度工具结果宣称为每个印刷末位都一致。
归档参考中的 J=9.8174e−6 按书中 Jp=Jy+Jz 与已舍入 Jy/Jz 得到，原页并未单独列出这一 J 表项。

## 工具与结果追溯

`src.solver.calculate_material_section(parameters)` 返回：

- 原始输入、输入单位、来源与 evidence；
- 可直接填入模型的 material、section；
- 输出单位、适用假定、理论文档路径；
- formula_version 与 calculation_id（原始输入及公式版本的 SHA-256）。

Agent 只提交原始参数。运行时保存 Python 结果，按材料/截面 id 填入候选模型；
原始识别 facts 仍保持 null/needs_calculation，computed_fields 单独标记 python_tool 及 calculation_id。
单位不一致或识别值与工具结果冲突则阻止确认；uncertain 不因存在一次参数计算而被覆盖。
用户修改输入后撤销旧参数缓存、结构确认及结果。参数计算本身不执行 Solver，不授权结构求解。

## 验证依据

`tests/test_parameters.py` 检查解析常数、参考资料录入精度、六种 E 单位、三种 R 单位、N/kN 缩放、
非法/缺失参数、溢出、实例修改后重校验、计算记录可追溯性及 Agent 参数填入/冲突/失效。
参考资料参数比较使用绝对容差：E 1e−8、G 500、A 5e−7、Iy/Iz 5e−11、J 1e−10，
分别为输出对应单位；J 的容差来自两个已舍入惯性矩的误差之和。
解析常数比较 rtol=1e−14、atol=0，避免只依赖参考资料的低精度录入值。
