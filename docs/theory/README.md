# 理论资料

此目录用于保存课程讲义、公式截图、推导文档和整理笔记。

原始资料保留在本目录；公式、来源和计算约定统一整理到根目录 [theory.md](../../theory.md)。不要把推测或标准理论补充写成课程原文。

收到资料后，按以下内容整理：

1. 基本假设与适用范围。
2. 单位、符号、坐标系与自由度编号。
3. 单元计算公式与坐标变换。
4. 整体方程、边界条件与求解过程。
5. 内力、反力及其他结果的恢复方法。
6. 示例输入与参考结果。

已归档 10 份课件到 `course/`。详见 [资料索引](source-index.md)、[程序样式对照](course-program-style.md) 和 [勘误记录](errata.md)。`course/manifest.json` 保存文件来源、页数与 SHA-256。

后续继续核对教材与空间刚架推导，确认内容统一记录在根目录 theory.md。原课件中的提交日期或团队安排不会自动改变本项目的个人项目范围。
