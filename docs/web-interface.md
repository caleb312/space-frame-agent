# 本地交互页面

## 启动

在项目目录双击 `启动网页.cmd`。首次运行自动准备 `.venv` 和依赖，以后直接启动。详情见 [一键启动说明](../启动说明.md)。也可在已安装依赖的环境中运行：

```powershell
cd 'D:\space-frame-agent' # 替换为自己的项目目录
python web_main.py --open
```

默认地址 http://127.0.0.1:8765，只监听本机回环地址。保持服务终端运行，Ctrl+C 停止。
已有本项目服务占用此端口时，带 `--open` 的启动命令打开现有页面。
其他程序占用时，可添加 `--port 8766`，使用新地址。
Python 标准库 HTTP 服务用于个人本地课程演示，不用于公开网站部署。

不新增 Python 依赖，沿用 NumPy、Pydantic、Pillow 和嵌入式 Plotly.js。

## 使用顺序

1. 先点击左侧已保存的 IV-1、IV-2，查看模型、来源、程序结果表及三维图。这个操作不请求 API，不重新求解。
2. 点击“模型设置”：服务商支持 DeepSeek、Qwen、GPT。填写账号可用的模型名称、API 地址及密钥。
3. 按账号可用型号选择模型及API地址，确认该型号支持图片和工具调用。连接页采用通用设置，不显示供应商专属思考模式；输出上限沿用32768。
4. 本机已设置对应 `*_API_KEY` 环境变量时可以留空；同一运行会话已配置密钥时也可以留空沿用。GPT 还可读取项目 `.env.local` 中的 `OPENAI_API_KEY`，默认模型为 `gpt-4.1`、官方地址为 `https://api.openai.com/v1`。保存连接设置不代表已获得 API 回答。
5. “保存连接设置”只是本地配置校验，不请求付费接口，也不能证明密钥、模型权限和网络连接有效；第一次发送时才真正调用 API。
6. “新建分析”先存档当前记录，再清空工作区。上传完整题面和结构图，输入求解目标或识别要求，然后发送。
7. 使用“建模与纠正”输入自然语言补充信息，支持多行、Ctrl+Enter发送，不需要 `/paste` 或 `/end`。
8. 核对右侧模型、全部荷载及来源。存在阻塞项时不能确认；基本校验通过也不证明图片理解正确。
9. 点击“确认模型并计算”。按钮提交当前模型哈希，由应用授权，再调用已有 Solver。AI 无权代替点击确认。
10. 程序先保存数值结果和三维图。勾选“计算后生成解释”且已配置 API 时，再请求简短文字解释。解释失败不丢弃数值结果。
11. “结果追问”只解释当前已求解结果，不重建模型、不撤销确认、不重新求解；需要修改结构时使用“建模与纠正”。
12. 三维页支持色带、图层、投影和放大。内嵌版隐藏数值侧栏，详细数值见“计算结果”，或打开独立三维窗口。
13. 可以下载原始 JSON、模型、识别记录、结果表、解释和离线三维 HTML。原始结果的 course_clockwise 正号保持不变。

## 会话保存与恢复

- 每个浏览器会话使用本地 cookie 对应的随机目录：`results/web_sessions/<会话编号>/`。
- `session.json` 保存对话、当前记录、模型、结果及非敏感连接设置；写入使用同目录临时文件替换。
- `input_*.jpg` 是落实 EXIF 方向后的上传图像，上传预览在发送前不会调用 API。
- 新建分析及修改已求解模型前，会先保存历史到本会话 `history/`；已求解结果另存到 `results/web_*.json`，可从保存列表重新打开。
- 相同模型哈希的保存结果在列表中合并，优先显示 IV-1/IV-2 原文件。
- 每条保存计算下方可点击“改名”或“删除”。改名只改变列表显示名称，按模型哈希存入 `results/.saved_catalog.json`，原文件名、模型和数值保持原样。
- 删除须确认；同一模型的重复保存结果及已知配套文件移入 `results/.trash/<记录编号>/`，其中 `manifest.json` 记录原文件名。删除当前打开的保存计算后，工作区仍可查看，自动存档不会把该模型重新加回列表；修改为不同模型后仍可正常保存。回收目录暂未提供网页恢复入口。
- 刷新页面仍使用内存 Agent；重启服务后恢复对话和结构记录，但不恢复供应商原始消息/思考内容，用当前结构记录构造后续上下文。若上轮请求中断，应核对记录并重新发送未完成的补充。
- 重启后草稿必须重新确认，已保存结果可直接查看。会话切换或清理浏览器 cookie 后，可从保存结果列表重新打开已求解模型。
- 页面填写的密钥只存在当前进程内存，不写入 session.json、导出文件或浏览器存储。GPT 可在用户批准保存后读取项目 `.env.local`，环境变量优先；自动读取的文件密钥仅允许发送到官方 API 地址。配置文件已被 `.gitignore` 排除，勿作为作业附件分享。
- 解释本地等待上限仍为60秒，超时不保证供应商服务端同步取消。断开连接阻止后续调用，不承诺取消已发送请求。
