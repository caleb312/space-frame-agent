# 原生桁架与平面刚架验证（2026-10-11）

## 计算依据与边界

阎军、杨春秋2014《计算结构力学》，定位见 `../theory/planar-truss-frame-2014.md`。平桁2平动、空桁3平动、平刚2平动+顺时针转角；自编LDLT与回代，无虚拟转动刚度、附加支座或伪逆。旧空间刚架模块及算例保持回归。

桁架仅接受节点集中力；平刚位于明确选定的二维XY系，只接受平面内力/力矩，支持已实现的跨内集中与常值区间荷载。释放、刚臂、剪切、非线性不在当前范围。

## 独立参考与实际误差

三个算例为自定义解析验证题，不是教材原题复现。参考值来自静力平衡、轴向兼容及悬臂解析式；没有把Solver自身输出作为参考答案。

| 算例 | 关键解析结果 | 最大位移误差 / m或rad | 最大反力误差 / kN或kN·m |
| --- | --- | --- | --- |
| 三角平面桁架 | 底杆N=5kN，两斜杆N=-5√2kN，两支座Ry=5kN | 8.47e-22 | 8.88e-16 |
| 2m平面悬臂 | uy=-PL³/(3EI)=-0.001333333333…m，原始顺时针rz=0.001rad；页面右手rz=-0.001rad | 8.67e-19 | 1.07e-14 |
| 三维正交三杆 | 自由节点U=[3,-4,5]/EA，各杆N=[-3,4,-5]kN | 4.24e-22 | 4.44e-16 |

完整解析参考、误差及整体平衡残差：`../../results/midterm_examples.json`。三类模型都已通过主程序CLI入口独立运行，诊断输出位于 `work/*_cli.json`。
