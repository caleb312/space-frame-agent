# 平面刚架及平面/空间桁架：2014教材依据

依据用户提供的阎军、杨春秋《计算结构力学》2014，不使用钟万勰算法。
印刷页p对应PDF p+9；以下页已实际渲染核对。

- p31，式2-7、2-8、2-9：平桁2平动、空桁3平动、平刚2平动+1转动。
- p32，式2-11/2-12：轴力局部端力向总体的方向余弦变换。
- p34及p78：平刚6×6局部单刚、4个3×3分块；耦合项按顺时针转角为负/正。
- p79：T=[[c,-s,0],[s,c,0],[0,0,1]]；全局单刚T k Tᵀ，局部位移TᵀU。
- p84、p90-93：跨内荷载通过固定端力反作用形成一致节点力，端力需扣除原跨内等效荷载；截面通过静力平衡恢复。
- p67、p70：空间桁架方向余弦向量及EA/L刚度；平面桁架取其二维形式。组装为EA/L*[nnᵀ,-nnᵀ;-nnᵀ,nnᵀ]，轴力N=EA/L*n·(uj-ui)，受拉为正。
- p70式3-19将cosγ分子印为zR-zR；同页ch代码为z[j]-z[i]，本项目采用zR-zL，记录为本次核对排印差异。

输入约定：plane_truss坐标[x,y]，约束[ux,uy]；space_truss坐标[x,y,z]，约束[ux,uy,uz]；plane_frame位于自定义二维XY坐标，约束[ux,uy,rz]。plane_frame顺时针rz/Mz为正，空间刚架现有course_clockwise不变。
所有荷载均须明确坐标；桁架首版仅节点力，无节点力矩/杆上横向力；平刚支持节点力/力矩、跨内集中力/力矩及常值区间分布力，复用已验证Hermite积分与截面静力恢复（frame的局部z方向垂直XY平面）。不能自动忽略不支持荷载。

采用明确编号映射、刚度四分块累加、现有自编LDLT和前代/回代，支座位移为零；不加虚构约束，不用伪逆掩盖机构。

验证计划：轴力杆/三角桁架/三维三杆节点的独立解析平衡；平面悬臂的轴向、集中力、力矩与均布荷载解析解；2014例2-1的输入/位移对照；现有空间算例回归。验收范围和实际执行结果另行记录。
