# 课程需求与阶段计划

## 最终效果

用户上传空间刚架结构图片并用自然语言提问，系统提取结构信息、补齐必要信息、校验模型，调用确定性的 Python Solver，最后依据数值结果回答问题。

完整流程：图片与问题 → 模型提取 → 信息澄清与校验 → Solver → 数值结果 → 自然语言回答。

本项目为个人学术课程大作业，重视可复现的正确计算与清晰说明。

## 已确定范围

- Python；优先使用 NumPy、SciPy、Pydantic，按需引入。
- 线弹性三维空间刚架、直接刚度法、两节点 3D frame / beam 单元。
- 每节点 6 个自由度：ux、uy、uz、rx、ry、rz。
- 第一版处理节点集中力与节点集中力矩。
- 用户后续授权扩展杆上集中力/力矩、分段均布力及指定截面内力，通用接口已实现。
- 输出节点位移、支座反力与杆端内力。
- Solver 独立计算，Agent 调用工具并解释结果，图片识别最终接入。

第一版不纳入非线性、动力和时程、屈曲、优化、抗震规范自动设计、商业软件级错误处理、云端部署、多 Agent、数据库及生产部署设施。完整约束见 [AGENTS.md](../AGENTS.md)。
