## 已确认的定义

1. p380：N为节点总数，M为杆件总数，NC为六个位移全部被约束的固定端节点数；KE为杆件弹性性质类别总数，KG为杆件几何性质类别总数。
2. p380：约束位移排列为U、V、W、thetaX、thetaY、thetaZ。NC=0不表示没有支座，本例约束另由UE0/U0输入。
3. p381：EGF给出的六列为EF、EJy、EJz、GJd、mu_y GF、mu_z GF，即组合刚度输入，不是单独E/A/I/J原始物理参数。p384例题1通过给剪切刚度很大值近似不考虑剪切变形；本例列出有限剪切刚度，不能静默套用现有Euler-Bernoulli实现。
4. p381：GO的DAX/DAY/DAZ/DCX/DCY/DCZ对应第六章第一节定义的端部偏移分量，sina定义也须回查该节。不能仅把GO每行解释成左右各0.5m。
5. p381：SCT的XP正实数表示指定截面距离；负整数-S表示S个均布截面。p389本例16根杆XP均为-2，是每杆两个均布截面请求，不是负的物理坐标，也不是只取跨中。
6. p381-382：IND的符号用于区分主惯性平面：A'X'Y'平面用正，A'X'Z'平面用负；其绝对值为荷载类型编码。对于轴力/扭矩的特殊编码，p382另有说明。不能直接把IND=-6翻成负的第六自由度分量，或把IND=3当全局z方向。
7. p382、p386：转角与力矩矢量按右手螺旋法则；与现有course_clockwise负右手约定必须显式转换。截面内力正号应按本书图I-11核对，不直接默认等同此前textbook_section。
8. p387：例题2为14节点、16构件；题面注明柱右端刚臂0.5m、横梁两端刚臂各0.5m，节点1和8为铰支承；P1=12吨、P2=8吨、长度单位m。暂保留教材原始单位，后续统一力单位时须记录换算约定。
