## 约定差别

- 课件及正文使用负右手旋转分量；附录 p194 的耦合项相反，采用右手分量。D6=diag(1,1,1,−1,−1,−1) 显式转换每端的转角/力矩，单刚关系为 D12·k·D12。核心接口保持课件约定。
- 正文 p119 式5-6 的一般杆局部 y 在总体 z 方向的分量为负；附录 p183 式IV-3 的基准方向相反。它们是不同的零截面转角约定，不能对非圆截面混用。
- 附录的竖直正/负向杆有特殊式。非零截面转角测试逐项核对这些式子，避免只验证 θ=0。
- `textbook_basis` 仅用于明确选用的参考资料轴规则，不从图片自动猜截面朝向。一般模型仍要求显式 local_y。
- 例题为圆截面，可按书中 Jp=Iy+Iz；一般截面仍输入 Saint-Venant 常数 J，不自动套用圆杆关系。

## 原题复现与数值结果

两题有跨内荷载，超出第一版 Solver 的直接输入范围。验证适配器执行：原题数组 → Hermite 虚功等效节点力 → 附录力矩转课件分量 → 同一个 Solver → 原题固定端力/指定截面力恢复 → 转回附录约定 → 印刷答案对照。

`examples/textbook_reference.py` 是验证适配器，不是 Agent 工具或新增的通用跨内荷载接口。原题和答案保存在 original.json，equivalent_nodes.json 是显式转换后的节点模型；该节点模型单独运行 main.py 时，杆端力仅为其位移项，不能直接当作原跨内荷载结构的真实端力。

截面恢复使用真实左端作用力与截面左侧原荷载的静力平衡，集中力位置取荷载右侧，并明确转换截面 N/Q/T/M 的正号。
