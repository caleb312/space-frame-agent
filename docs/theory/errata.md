# 课件差异与勘误记录

课件页码为 PDF 物理页码；参考资料同时给出印刷页和 PDF 页。下列内容保留原件，通过验证指出差异。

## E01：四杆平桁节点 3 的竖向位移符号

来源：C06《6－3章平桁总刚累加规律及累加子函数-中文.pdf》p4、p15、p16、p20。

p4 荷载为节点 3 和节点 4 的水平 +P、竖向 −P。p15 的无量纲总刚为：

```text
[(√2+1)/2, 1/2, -1/2, -1/2]
[1/2,       1/2, -1/2, -1/2]
[-1/2,     -1/2, 1+√2,    0]
[-1/2,     -1/2,     0,    1]
```

将该矩阵与 `[1, −1, 1, −1]` 交给 NumPy 确定性求解，得到位移系数：

```text
[2√2, −2(3+2√2), −√2, −(√2+4)] × Pl/(EA)
```

p15/p20 印出的第二项为正，与其矩阵和荷载不一致。将印刷值代回，归一化平衡残差为 `[6+4√2, 6+4√2, −(6+4√2), −(6+4√2)]`，非零。纠正第二项符号后满足该方程。

状态：已对课件页面图像核对，并执行该 4×4 方程的独立求解。后续 Solver 回归测试应使用纠正后的位移，并保留本记录。尚未完成结构建模/组装/轴力的完整程序验证。

## E02：轴力求解流程图中的位移差

来源：C07 p16 与 p18。

p16 的 V(2) 在自由端分支写成 `DP(J0+2)-DP(J0+2)`；p18 程序为 `dp[j0+i]-dp[i0+i]`。按左右节点对应位移实现，不照抄同项相减。桁架子程序仍不在当前空间刚架核心范围内。

## E03：正文与附录的分量约定

这是一项约定差异，不直接认定为印刷错误。参考资料 p124（PDF p133）与附录 p194（PDF p203）的平移—转动耦合项反号；旋转/力矩的显式变号可建立对应关系。正文 p119 与附录 p183 的一般杆基准局部 y/z 方向也相反。项目保留课件约定，通过适配器复现附录；矩阵及非零截面转角测试已添加，详见 textbook-audit.md。

## E04：例 IV-2 的两个印刷 x 位移

参考资料 p188（PDF p197）原印刷值为节点 4：40.0025641 m，节点 5：50.0025679 m。原值完整保留在 `textbook_iv2_original.json`。

对原题建立的独立 Hermite 能量积分方程，将原表位移代入自由方程时，残差分量超过 1e5（按分量分别为 kN 或 kN·m）。独立积分和教学 Solver 均得到约 0.0025640644 m、0.0025678863 m，与删除前导节点号后的 0.0025641、0.0025679 相容。

项目对照值另存于 reference_displacements_corrected，并记录 project_errata；原印刷值没有被覆盖。报告标记原印刷整表未通过。这是项目核对的更正，不声称是出版社正式勘误。测试通过独立方程验证差异，不能改写为“所有印刷值原样通过”。

## E05：例III-1题面截面参数与答案不匹配

来源：项目计算规则印刷p168–169 / PDFp177–178，附录III.8例III-1。
原题及输入表均给E=200GPa、A=0.1m²、Jz=5×10^-6m⁴；原位移/9项截面结果原样另存，不覆盖。

按这些条件，修正后的Solver与独立手列节点4的3×3方程一致。
印刷位移代入该方程的残差为[13.3043833kN,-18.98825kN,-1.3951kN·m]，超过其7位小数舍入可能造成的上界。
同方程float32 LDLT和float64结果之差约1e-14m、2.2e-12rad，无法解释本次差异。

只把截面改为A=0.03m²、Jz=7.162×10^-5m⁴，其他几何/荷载/E保持例III-1不变，即复现答案：
节点三项位移按7位小数完全相同，9项内力均在float32一个ULP加印刷半末位容差内。
最大力差约3.87e-7kN，最大弯矩差约2.57e-8kN·m。
这组截面参数正好出现在p169的下一例III-2，因此答案疑似沿用了下一例截面参数。
能够确定的是题面与答案不匹配，不能仅凭扫描本判断错误在题面、实际输入还是编辑过程，不声称出版社正式勘误。

比较时②杆按参考资料3→4统一局部方向；工作台原4→3的跨中弯矩须反号，且集中力截面比较right极限。
此前顺时针错填Mz=-5为独立的Agent输入问题，已修正；本核对一律采用Mz=+5。
核对程序examples/audit_textbook_iii1.py，原印刷值与报告results/textbook_iii1_audit.json/.md；核心Solver与当前用户模型均未改动。
