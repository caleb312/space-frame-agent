## 验证边界

- 指定参考资料原件现已取得，第五章和两道附录空间题已按记录的方法核对；C06 四杆平桁仍只作为 LDLT/回代测试，不宣称另行实现完整桁架 Solver。
- 第一版针对直杆、等截面、截面主轴对齐的无剪切线弹性模型；未验证第一版范围外的作用和非线性分析。
- 数值主元阈值可能拒绝极端病态模型，不能把诊断解释为已经完成商业软件级稳定性判别。
- Agent 与图片提取尚未实现，当前交付为可独立使用的计算核心。
- 核心仍直接接受节点荷载；原书跨内荷载的复现在验证适配器中完成。不得把验证适配器说成通用工程功能，也不得忽略 IV-2 原印刷整表未原样通过的事实。
