# 图 I-12 简化条件（现有2014课程Solver输入）

用户批准的简化：忽略杆端刚臂、忽略剪切变形；采用节点间全长Euler–Bernoulli单元。保留原组合刚度和荷载偏心产生的集中力矩。求解器未改动。

## 来源、换算和建模选择
- 原条件：钟万勰《计算杆系结构力学》附录一例题2印刷p387–389。荷载及局部坐标核对p363–371。只翻译条件，不引入其计算算法。
- 求解规则：阎军、杨春秋2014课程Solver及已确认项目规则；units=kN_m，convention=course_clockwise。
- 原题“吨”按标准吨力tf解释，1tf=9.80665kN；力、力矩、EA、EI、GJ全部由Python统一换算。
- 保留节点坐标。④⑭杆柔性段起点比节点i沿杆向上0.5m；原XQ2.5换成节点端距离3.0m。⑥⑯仍9.6m，四处荷载高度均z=9.6m。
- 忽略原有限剪切刚度与所有端偏置，弹性杆长改为节点间全长。
- E_ref=210000000 kN/m²、G_ref=E_ref/2.6是用于拆分EA/EI/GJ的归一化计算基准，不是原题真实材性。Python生成A=EA/E_ref，Iy=EIy/E_ref，Iz=EIz/E_ref，J=GJ/G_ref，确保组合刚度不变。不假设真实截面形状，不据此计算应力或设计截面。
- 所有截面Iy=Iz；local_y按原sinα=0取向明确赋值，详见下表。

## 输出与后续Agent使用
- 每杆请求i端右侧和j端左侧截面内力，共32个截面；同时输出节点位移/转角、支座反力、杆端内力与确定性杆内变形图。
- 后续只上传第一张原结构图及本说明。参数以本说明及examples/i12_simplified.json为准，不再识读原参数三张截图，不调用圆截面E/nu/R参数工具，不把归一化参数视为实际截面。
- 用已有Solver求解的是本简化模型，不能声称与含刚臂/剪切变形的原教材答案精确一致。
- results/i12_simplified.json可在工作台保存计算列表打开；model.html仅几何和荷载，3d.html包含当前求解结果。
