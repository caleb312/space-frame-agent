# 课件程序样式对照

本项目使用 Python，Solver 保持课件的面向过程组织方式：数字化数据 → 几何与单刚子函数 → 对号累加 → LDLT 三角化 → 回代位移 → 杆端力/反力输出。当前已按以下对照完成第一版，实际验证见 ../validation/README.md。

## 主程序与函数

| 课件函数 | 保留的职责 | 空间刚架扩展与注意点 |
| --- | --- | --- |
| i0j0 | 杆两端位移对号 | 完全固定节点排前时推广为 6(i−nc−1)；部分约束和非连续外部编号须有显式映射 |
| ch | 杆长和方向余弦 | 使用 x/y/z；三维弯曲杆还需确定局部 y/z 轴，不能仅凭杆轴方向确定截面转向 |
| stif | 局部单刚及转换后的四分块 | 保留 rda/rdb/rdd/rde 与 ca/cb/cd/ce；空间刚架每块 6×6，不可套用桁架的单块 ±C |
| trnsps | 矩阵转置 | 与课件的力转换方向一致，转置后不破坏原矩阵 |
| mtmult | 矩阵乘法 | 记录维度，保留清晰的中间计算关系 |
| dor | 单元循环、总刚清零及累加 | 四分块分别累加入节点对应位置；K21=K12ᵀ，不要求 K21=K12 |
| ldlt | 改进平方根法 LDLT 分解 | 保留独立分解步骤；受约束后的稳定系统才具有求解所需正定性 |
| slveq | 前代、对角求解、回代 | 求节点位移；不能只用一个黑盒求解函数替代课程要求的分解/回代展示 |
| doh | 内力恢复 | 桁架的 h[m] 扩展为每杆两端共 12 个局部杆端力 |
| dofanli | 支座反力 | 与 C07 p25 的杆端力转换/累加思想对应；保留原荷载及所需原刚度信息 |

对应来源：C05 p19～28、C07 p9～11/p19～25、C09 p24～36、C10 p5～14。资料编号见 source-index.md。

主程序应逐步写明输入、变量数组、dor、ldlt、荷载列阵、slveq、位移输出、doh、dofanli 和结果输出。提供中文注释，方便对应课件与答辩讲解。

## 数字化数组

保留 n、nc、m、nn、x、y、z、ihl、ihr、ea、clxy、i0、j0、r、dp，以及四个局部/总体刚度分块的含义。

- 空间刚架需要两个主轴弯曲刚度与扭转刚度；不能只增加一个 z 数组就认为完成了空间扩展。
- 课件 dp 先存荷载后存位移。Python 实现可保留此教学过程，但必须保存原荷载副本，防止反力恢复和结果追溯时丢失荷载。
- 使用 Pydantic 时仅承担输入数据校验；不将全部计算改为复杂的类继承体系。
- 为任意外部编号提供映射，同时提供课件“先固定后可动”的数字化演示。
- 第一版可以使用课件允许的完整方阵 r[nn][nn]。带状存储后续按需要加入，不把它误写成当前已实现功能。
- 第一版只有节点集中力/力矩，不调用跨内荷载的 force/cudp/dodp；若后续扩展须另补固定端力与算例测试。

## 样式验收

实现后应能在主程序中逐项看到课件计算流程，检查每个函数的输入输出及数组维度，展示局部与总体单刚分块、总刚、分解结果、位移、反力和杆端内力，并将数值与独立参考答案比较。

## 实际代码位置

- `main.py`：JSON 数字化文件入口，中文主步骤注释。
- `src/solver/analysis.py`：digitize → dor → ldlt → slveq → doh → dofanli 的完整主流程。
- `src/solver/assembly.py`：课件数组、i0j0、dor 的自由分量直接对号累加，同时保留反力所需的完整 K/P。
- `src/solver/geometry.py`：ch、trnsps、mtmult 与明确标记的三维局部轴。
- `src/solver/stiffness.py`：stif，局部与总体 6×6 四分块及中间乘法。
- `src/solver/equations.py`：ldlt 和 slveq；没有调用黑盒线性方程求解替代教学步骤。
- `src/solver/recovery.py`：doh、dofanli 和总体平衡。

Python 的数据记录仅用于传递参数和结果，计算过程仍由独立函数执行。测试使用标准库 unittest；这不改变 Solver 的课程组织方式。
