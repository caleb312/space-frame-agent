# 中期演示验证顺序

## 已实现的范围

空间刚架（旧入口）、平面刚架、平面桁架、空间桁架。原生DOF分别6、3、2、3；结构类型不明确时先澄清。平刚仅XY二维坐标、平面内荷载；桁架仅节点力、铰接轴力单元。刚臂、剪切修正、内节点释放、非线性仍不支持。

## 先做简单平面题

建议先新建分析，导入examples/plane_truss_triangle.md，再导入plane_frame_cantilever.md分别建模验证；文件只含给定条件，没有参考答案。文字条件通过后，再单独用PNG检验图片识别。详细执行记录见docs/validation/native-structures.md。

1. 在保存结果列表打开plane_truss_triangle.json，查看解析验证后的位移、反力和三杆轴力。
2. 新建分析，上传examples/plane_truss_triangle.png，不携带旧模型；请求“判断结构类型并说明依据，建立识别记录，不求解”。核对类型plane_truss、3节点3构件、节点30全局Fy=-10kN，E/A以及支座正确。
3. 人工确认计算；底杆N=+5kN，两斜杆N=-7.071067811865...kN；反力Ry各5kN。数据应与保存基准一致。
4. 用plane_frame_cantilever.png重复独立流程。核对类型plane_frame、2节点1构件、固定节点10、自由节点20、10kN向下。
5. 确认后自由端uy=-0.001333333333...m，course_clockwise rz=+0.001rad，页面右手转角显示-0.001rad；支座Ry=10kN、右手Mz=20kN·m。
6. 接着验证space_truss_three_bar.json原生3D轴力计算。真实图像分类可能出错，仍须核对，不宣称已通过全部图片自动识别。
