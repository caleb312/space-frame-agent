# 保存计算的改名与删除

2026-10-13 更新记录。

## 行为

- 左侧每条保存计算显示“改名”和“删除”按钮，各操作使用独立弹窗。
- 改名保存1至100字符的显示名称，按模型哈希绑定；文件名、模型、原始计算数值保持原样。刷新页面和重启后名称仍可恢复。
- 删除经确认后，把同一模型哈希的重复结果和已知配套文件一起移入 `results/.trash/<记录编号>/`，记录清单。没有递归删除。
- 当前工作区的结果可以继续查看；删除标记阻止自动存档把相同模型重新列出。不同模型仍可正常保存。
- 目录管理复用工作台会话令牌和本机来源检查。忙碌会话拒绝管理操作；路径仅限结果目录的已列出记录，拒绝越界和符号链接。
- 当前版本没有网页回收恢复入口，文件保留在本地回收目录。
