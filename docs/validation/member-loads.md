## 独立检查

不只与旧适配器比较，还检查：

- 六分量点荷载的合力/合力矩，常值区间荷载的合力与形心力矩。
- 已知多项式位移场的虚功积分。
- 两端固定均布梁固定端力、悬臂全跨/部分均布荷载解析位移。
- 跨内集中力/三轴集中力矩的解析位移及左右截面跳跃。
- 单元端点反向、全局/局部坐标输入、均布区间分段叠加、每杆静力平衡与 N/kN 缩放。
- 非法位置/区间/编号/维度、跨中位置由程序计算。
- Agent 从独立荷载清单生成 member_loads，缺失坐标系/区间/方向或非均布分布仍阻止求解。
- 程序确认后可调用 Solver，未确认时不求解；指定截面缺失时不擅自用杆端力替代。
